# Ejemplo del manual de usuario

Los archivos de esta carpeta contienen las entradas y los resultados del ejemplo del manual.

- `ejemplo-entradas.txt`: datos ingresados.
- `ejemplo-salida.txt`: salida del programa.
- `pruebas.txt`: resultado de las 62 pruebas de Python.

El ejemplo registra P01 con precio 12.50 y existencia 3. La venta de 2 unidades da subtotal 25.00, IVA 3.00 y total 28.00. Después de una entrada de 4 unidades, quedan 5 y el valor del inventario es 62.50.

Una línea vacía en las entradas representa Enter. Cada ejecución inicia sin datos.
